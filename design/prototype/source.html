TidyMyMac layout prototype

A clickable sketch of the v1 app: every module in the sidebar, the Smart Care scan, review and clean flow, the menu bar extra and first-run setup. All files, sizes and apps are made-up examples. Nothing here touches a real Mac.

Appearance

Try this

  • Smart Care: Scan, then Review All, untick a few items and Clean.
  • Space Lens: click a folder tile to drill in, tick items in the list.
  • The sweep glyph in the menu bar opens the monitors and alerts.
  • The status line under the sidebar opens first-run setup.

What it settles

  • Nine sidebar modules in three groups; My Tools is a launcher, not a tenth engine.
  • Every clean goes through the same review list and one confirmation that names Trash vs permanent.
  • Risky items (iOS backups, AI models) never appear in Smart Care and have no select-all.

Not real yet

  • App icons in lists are placeholders; the real app draws each app's own icon.
  • The admin password prompt is a macOS system dialog, so it is only described here.
  • Liquid Glass is drawn by macOS 26 itself; this sketch only hints at it.
