# TidyMyMac 1.0.3

Build 4. The `v1.0.3` tag goes on the merge commit of the pull request that adds this file, after `scripts/release-gate.sh` passes on it; the gate's report is the tag's message.

## What's new

**Sort every item table (#86).** Click a column header to sort Declutter's Large & Old and Downloads tables, the Uninstaller's related files and Run History, as the Cleanup list already did. Until you click one, each table keeps its usual order. In the Uninstaller the app itself stays on top.

**Check All and Check None (#86).** These buttons sit above the Cleanup list, Declutter's Large & Old and Downloads tables and the Uninstaller's related files, and in Tidy Up's Review sheet. They act only on the rows shown, so a filter limits what they change. Check All never checks risky items: you still check those one by one. Duplicates, Leftovers and the Uninstaller's app list have no Check All on purpose.

## Behind the scenes

- **Release gate publishes (#85).** After a pass, `scripts/release-gate.sh` asks once and then tags, pushes and creates the GitHub Release itself.

## Gate

The short form applies: only `App/`, docs and scripts changed since `v1.0.2`. SafetyFloor, HelperCore, Helper, RuleEngine and Rules are unchanged, so there are no canary or `tidytest` steps. No rules changed.
