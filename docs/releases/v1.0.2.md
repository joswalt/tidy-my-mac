# TidyMyMac 1.0.2

Build 3. The `v1.0.2` tag goes on the merge commit of the pull request that adds this file, after `scripts/release-gate.sh` passes on it; the gate's report is the tag's message.

## What's new

**Quit open apps before cleaning their caches (#80).** Cleanup used to clean a cache folder while its app was still open when the folder wasn't named exactly like the app's bundle ID. For example, `~/Library/Caches/Google` was cleaned while Chrome was running, and the clean failed. TidyMyMac now also recognises a cache by its app's name (`CodexBar`), or by the company part of the app's ID (`Google` → `com.google.Chrome`, Dock apps only). These items now appear in the list. After you confirm a clean, a sheet lists the open apps with **Quit**, **Quit All**, **Ignore** and **Cancel**. Quit asks the app to quit the normal way and never forces it. Items of apps you leave open are skipped and logged as "*App* is running", not as Failed. The same applies in Tidy Up.

**Sort the Cleanup list (#80).** Click a column header to sort by Name, Location, Risk, Goes to or Size. The order stays the same as you move between categories.

## Behind the scenes

- **Release gate script (#82).** `scripts/release-gate.sh` runs the release checklist and stops only for the steps that need a person in the app.
- **User-level canaries (#82).** Script-made canaries in your own account replace the permanent `tidytest` account. A temporary `tidytest` is created and deleted only for releases that change the helper or the safety floor.
- **Worktrees (#81).** Agent worktrees now live in the git-ignored `.worktrees/` folder.

## Gate

The full form applies because `RuleEngine` changed (#80). No temporary `tidytest` account is needed, because SafetyFloor, HelperCore and Helper are unchanged since `v1.0.1`. No rules changed.
